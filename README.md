# PATakha World
Digital Diwali fireworks simulator. Static site (no build step): HTML canvas + Web Audio, installable as a PWA.

## Deploy
1. Push this folder's contents to a GitHub repo (index.html must be at the repo root).
2. On vercel.com: Add New > Project > import the repo. Framework preset: Other. Leave build command and output directory empty. Deploy.
3. Open the Vercel URL on your phone. Android Chrome: menu > Install app. iPhone Safari: Share > Add to Home Screen.

## Run locally
`python3 -m http.server 8000` then open http://localhost:8000
